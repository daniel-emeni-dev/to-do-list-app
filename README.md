# Todo Tracker

A simple, sleek, and responsive task tracking app for managing your daily todos. Add, edit, delete, and complete tasks with a clean interface built entirely with vanilla web technologies.

## Overview

Todo Tracker is a lightweight productivity app designed to help you stay on top of your daily tasks without any unnecessary complexity. No frameworks, no dependencies, just plain HTML, CSS, and JavaScript delivering a fast and reliable experience.

## Features

- Add new tasks quickly
- Edit existing tasks
- Delete tasks you no longer need
- Mark tasks as complete
- Fully responsive design that works on mobile, tablet, and desktop
- Clean, distraction free interface

## Tech Stack

- HTML5 for structure
- CSS3 for styling and layout
- Vanilla JavaScript for functionality and interactivity

No external libraries or frameworks were used, keeping the app fast and easy to understand.

## Getting Started

To run this project locally:

1. Clone the repository

```
git clone https://github.com/daniel emeni dev/todo tracker.git
```

2. Navigate into the project folder

```
cd todo tracker
```

3. Open `index.html` in your browser

That's it. No build tools or installations required.

## Usage

1. Type a task into the input field
2. Click the add button (or press enter) to save it to your list
3. Click on a task to mark it as complete
4. Use the edit option to update a task's text
5. Use the delete option to remove a task permanently

## Responsiveness

The app adapts smoothly across screen sizes, so you can manage your tasks whether you're on a phone, tablet, or desktop browser.
